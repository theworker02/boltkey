# boltkey

Bolt URLs and key query parts with stable normalization.

**Site:** https://theworker02.github.io/boltkey/

## Install / run

```bash
git clone https://github.com/theworker02/boltkey.git
cd boltkey
node src/cli.js
node --test
```
